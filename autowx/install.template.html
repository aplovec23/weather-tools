AutoWx
PAGASA weather stations

A friendly display for PAGASA automatic weather stations. It works inside the PAGASA Collection System while you are signed in, and only reads data.

1. Add the button

Show your bookmarks bar (⌘⇧B in Chrome, Edge or Safari), then drag this button onto it:

AutoWx

Can’t drag it?

  1. Click
  2. Right-click the bookmarks bar and choose Add Page… (in Edge: Add page; in Safari, bookmark any page first, then Edit Address).
  3. Name it AutoWx, click in the URL box, paste (⌘V), and click Save.

2. Use it

  1. Open cserv.panahon.gov.ph and sign in as usual.
  2. Click AutoWx on your bookmarks bar.
  3. Allow location when asked. The nearest working station appears first.
  4. Use ➕ Stations to add more stations, or Station status to check every station.

It updates every 10 minutes. Exit takes you back to the normal AWS page. Station locations ({{COUNT}}) are approximate town centres, which is close enough to pick the nearest station.

No bookmarks bar?

Sign in, open the browser console (⌥⌘J in Chrome), paste the code, and press Enter.
