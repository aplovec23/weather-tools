# Weather Tools

Small tools for weather observation and forecasting work in the Philippines.

## Tools

- [**AutoWx**](autowx/) — a bookmarklet that shows automatic weather station (AWS) readings from the PAGASA Collection System in a clear, kid-friendly display, with a station status board and a maintenance check. Requires a PAGASA cserv account; it only reads data.
- [**AutoCastWeather**](autocastweather/) — bookmarklets that build ready-to-post Facebook forecast updates from PAGASA forecasts: **ZAM Forecast** (Zamboanga City) and **DIP Forecast** (Dipolog, English + Cebuano).
- [**Similar Cyclone Finder**](similar-cyclone-finder/) — an offline page that finds the past western Pacific tropical cyclones most similar to a current one (by whole track, then strength) and shows what they did next.
