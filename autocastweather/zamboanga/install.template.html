Zamboanga 24-Hour Forecast bookmark

Writes the Facebook post text from PAGASA's latest forecast and shows the latest Himawari IR1 satellite animation.

⛅ ZAM Forecast

Install: drag the blue button onto Chrome's bookmarks bar.
Bookmarks bar hidden? Press ⌘ Shift B.

If dragging doesn't work: then right-click the bookmarks bar → Add page…, name it ZAM Forecast, and paste into the URL box.

Use
  1. Open pagasa.dost.gov.ph (any PAGASA page). Click the bookmark anywhere else and it offers to take you there.
  2. Click ZAM Forecast. A panel opens with the post text and the satellite GIF.
  3. Check the text (edit it in the box if needed), then Copy text and paste into your Facebook post.
  4. To attach the satellite animation: Open GIF to save, right-click it → Save Image As…, and add that file to the post.

Sunrise, sunset, moonrise and moonset are calculated for Zamboanga City and can differ from PAGASA's tables by about a minute. Temperature uses today's range for a morning forecast and tomorrow's for an afternoon one.
